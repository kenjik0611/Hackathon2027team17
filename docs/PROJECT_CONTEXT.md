### Git運用

READMEでは次の流れを推奨している。

1. 作業前に `main` の最新状態を取得する。
2. `main` に直接コミットせず、作業用ブランチを作る。
3. 変更をコミットし、作業ブランチをリモートへpushする。
4. Pull Requestを作り、レビュー後に `main` へマージする。

コミット、push、ブランチ作成は、担当者が内容と影響を確認したうえで行う。
