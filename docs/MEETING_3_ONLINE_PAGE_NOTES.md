# ミーティング #3（2026年8月23日）オンライン編 検討メモ

## このメモの目的

鈴木担当の「オンライン編」プロトタイプを作る中で見つかった、チーム共通画面や採点方法に関する検討事項を次回ミーティングへ持ち越す。

## 1. 場面選択画面の説明文

現在、`src/frontend/moral/main.html` のオンラインカードは次の表記になっている。

- 見出し：オンライン
- 説明：SNSやチャットでの場面

一方、担当テーマは「オンライン・Web会議」であり、プロトタイプでは次の範囲まで扱っている。

- Web会議と画面共有
- 在宅勤務の作業環境
- 業務チャット上のフィッシング
- オンラインでのファイル共有
- 誤共有後の初動

「SNSやチャット」だけでは出題範囲が狭く見えるため、共通画面の説明文を次のいずれかへ変更する案をミーティングで相談する。

### 表記案

1. `Web会議や在宅勤務での場面`（内容が最も伝わりやすい）
2. `オンライン業務での場面`（短く、今後の問題追加にも対応しやすい）
3. `Web会議・チャット・情報共有`（具体的だが少し長い）

今回は担当外ファイルへ触れない方針のため、`src/frontend/moral/main.html` は変更していない。

## 2. 採点方法として決めたいこと

現在のオンライン編には、動作確認用の仮採点として各問0〜2点を設定している。正式仕様ではない。

ミーティングでは次を決めたい。

1. 全担当ページで1問あたりの配点を統一するか
2. 完全正解だけでなく部分点を設けるか
3. 複数選択や危険箇所探しで、誤選択をどのように扱うか
4. 各ページ内で結果を出すか、モラル編全体で合計するか
5. 結果を点数、ランク、タイプ、コメントのどれで表現するか
6. 結果を人格や適性の判定にせず、学習の振り返りとして表現するか
7. 再挑戦時に同じ問題を出すか、問題バンクからランダム出題するか
8. ページをまたぐ場合に、得点をどこへ保存するか

## 3. 採点ロジックを変更しやすくする構造

`src/frontend/moral/online_Suzuki/online.js` 冒頭の `SCORING_CONFIG` に、次をまとめている。

- 採点表示の有効・無効
- 完全正解、部分正解、不正解の点数
- 結果画面の判定ラインと文言

正式仕様決定後は、まずこの設定を差し替える。問題固有の判定条件は各問題データと `evaluateAnswer` に分けている。

## 4. 現在の5問構成

1. 画面共有前の危険箇所を画像から選ぶ
2. 在宅勤務で席を離れる前の対応を選ぶ
3. ITサポートを装う業務チャットの危険サインを複数選ぶ
4. 私物クラウドや個人メールを使ったファイル共有を判断する
5. 誤共有後の対応を正しい順番に並べる

問題形式を変えることで、単純な三択が続かない構成にしている。

## 5. チームで揃えるとよさそうな項目

- 問題数と想定プレイ時間
- 問題ページの共通ヘッダー、進捗、戻る導線
- 正解後に表示する解説の構成
- 「モラル」という言葉をどこまで使うか
- PCとスマホの両方で操作しやすい回答形式
- 画像のテイスト、人物や端末を生成する場合の目視確認ルール

このメモは次回ミーティング用の検討材料であり、確定仕様ではない。
