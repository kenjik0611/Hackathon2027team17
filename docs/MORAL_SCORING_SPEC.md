# モラル編 採点仕様

## 目的と共通ルール

- この結果は、回答の振り返りと次の行動を考えるためのものであり、人格・仕事適性を判定するものではない。
- 個別パートの得点は、`Math.round(正解数 / 問題数 * 100)` で算出する。全パート100点満点である。
- 総合結果は単一の総合点を表示せず、常識・対応力・思いやりの3軸とタイプを表示する。
- 3軸の各値は `常識 / 対応力 / 思いやり` の順で0〜4点とする。
  - 4: その軸の模範的な判断
  - 3: 適切だが一部不足
  - 2: 良い面と課題が混在
  - 1: 弱い、遅い、リスクを残す
  - 0: 明確な無視・違反

実装上の安定IDと採点値は [`moral-core.js`](../src/frontend/moral/shared/moral-core.js) にあり、この文書は値付けの根拠を補う。

## 個別パートの正解

- 家庭: `correct` のみ正解。画面上では選択肢の表示順をランダム化する。
- 職場: 各設問の `idealIds` と3語が完全一致したときだけ正解。選択順は問わない。
- オンライン: 単一・複数・画像選択は正解IDの完全一致、順序問題は `idealOrder` の完全一致だけを正解とする。既存の部分正解は解説表示のみ。
- 社外: 各設問の既存 `answerIndex` に対応する `option-n` のみ正解。
- 公共の場: 各問の `option-1` と `option-2` を正解とする。どちらも既存3軸合計11点以上の妥当な判断である。

複数選択・語句選択では、選択した項目ごとの軸値を合計し、その問で取り得る上位3項目の合計を最大として0〜4へ正規化する。順序問題は、完全一致を4/4/4、最初に止めて報告がフォローより先なら2/3/3、それ以外を1/1/1とする。

## 総合結果

1. 各パート内で、全設問の各軸値の平均を100点換算する。
2. 5パートの各軸スコアを等しい重みで平均する。問題数の多いパートを優遇しない。
3. 各軸が70点以上なら「高」とする。

| 常識 | 対応力 | 思いやり | タイプ |
| --- | --- | --- | --- |
| 高 | 高 | 高 | 🌟 3軸バランスマスター |
| 高 | 高 | 低 | 🛡️ 信頼実行タイプ |
| 高 | 低 | 高 | 🤝 誠実気配りタイプ |
| 低 | 高 | 高 | 🫶 寄り添い対応タイプ |
| 高 | 低 | 低 | 📘 ルールナビゲーター |
| 低 | 高 | 低 | ⚡ スマートレスポンダー |
| 低 | 低 | 高 | 💛 思いやりサポーター |
| 低 | 低 | 低 | 🌱 伸びしろ発見タイプ |

各タイプの表示は「強み」「次に意識する行動」の順とし、断定的な人格評価は行わない。
